# Codex Live2D 桌宠

一个基于 Live2D 模型的透明桌面宠物：实时渲染、眼神跟随鼠标，并且能感知 Codex 的运行状态自动切换动作和表情；还内置了角色聊天模式，可以像朋友一样和角色对话。内置 **yumi** 模型，支持随时切换或导入其他 Live2D 模型。

![桌宠示意图](docs/preview.png)

## ✨ 功能

- **实时 Live2D 渲染**：QtWebEngine + pixi-live2d-display，无预渲染帧，角色一直在呼吸、摇摆
- **眼神/头部跟随鼠标**：光标在屏幕任意位置，角色都会看向它
- **Codex 状态联动**：读取 Codex 实时日志，自动切换状态
  - 待机 → 爱心眼 + 待机摇摆
  - 思考中 → 星星眼 + 托腮思考
  - 执行命令 → 蚊香眼 + 俯身忙碌
  - 完成 → 一次挥手
  - 故障 → 黑脸
  - 状态切换带柔和过渡动画，头顶气泡提示（思考中…/执行命令…/完成！/故障！）
- **模型切换**：右键 →「模型」子菜单可随时切换已安装的模型（yumi / 自行导入的模型）；当前模型会自动保存
- **动作预设 + 手动选择**：模型自带动作时自动采用，没有预设的状态回退到内置动作引擎
- **状态动作自定义**：右键 →「状态动作」可为每个状态（待机/思考中/执行中/完成/故障/点击互动）手动指定模型库里的动作、姿势或表情；未指定或指定的项不存在时，自动回退到默认动作配置
- **模型导入**：右键 →「模型」→「导入模型（zip）/（文件夹）」可直接导入新 Live2D 模型，自动识别表情、动作并生成配置
- **删除模型**：右键 →「模型」→「删除模型」可移除自己导入的模型（默认 yumi 不可删除）；删除当前正在用的模型会自动切回 yumi
- **聊天模式**：底部输入框和 yumi 对话
  - 回复以气泡漂浮在角色头顶
  - 根据回复情绪自动摆出动作和表情（开心→挥手爱心眼、难过→垂泪、生气→黑脸颤抖、思考→托腮、惊讶→后仰、中性→轻点头）
- **右键菜单**：模型、动作、表情、放松、聊天模式、聊天设置、锁定拖动、放大缩小、恢复默认设置和模型、退出
- **恢复默认**：一键把模型、大小、位置、锁定状态恢复为初始值（yumi）
- **透明置顶无边框窗口**，不挡工作区，窗口大小自适应角色，拖不丢

## 📦 环境要求

- Windows 10/11
- Python 3.10+（建议 3.12）
- 网络（首次安装依赖需要；聊天功能需要可用的 OpenAI 兼容接口）

## 🚀 快速开始

### 1. 安装依赖（项目本地虚拟环境）

```powershell
cd codex-live2d
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install PySide6
```

### 2. 配置聊天接口（可选，不配置也能用 Codex 状态模式）

复制 `config.example.json` 为 `config.json`，填入你的接口信息：

```json
{
  "chat": {
    "base_url": "https://api.deepseek.com/v1",
    "api_key": "你的 API Key",
    "model": "deepseek-v4-flash",
    "persona": "角色人设……"
  }
}
```

`config.json` 已被 `.gitignore` 忽略，不会提交到仓库（防止 Key 泄露）。也可以在桌宠右键菜单 →「聊天设置…」里直接填写，效果相同。

### 3. 启动

双击 `启动桌宠.bat`，或运行：

```powershell
.\.venv\Scripts\pythonw.exe main.py
```

出问题时用 `调试运行.bat`（带控制台）查看报错。

## ⚙️ 配置文件

- `config.json`：聊天接口配置（`base_url`、`api_key`、`model`、`persona`），本地生成、不入库
- `settings.json`：窗口位置、大小、锁定状态、当前模型，运行时会自动保存
- 每个模型一个目录：`model/<id>/`，目录内的 `model.json` 声明模型文件名、动作预设、表情映射和状态绑定

```

├── tools/web/
│   ├── live.html / live.js  # 实时渲染页面（动作、表情、眼神追踪、聊天 UI）

└── docs/                    # 文档与截图
```

## ❓ 常见问题

**启动后看不见小人？**

- 确认只启动了一个实例（重复启动可能互相遮挡）；右键多余的实例选择「退出」
- 桌宠不会掉出屏幕（已做边界限制），但可能被全屏应用盖住，可先最小化其他窗口
- 查看 `pet_error.log`（有报错时自动生成），把内容反馈给开发者

**聊天没反应 / 提示连接失败？**

- 在「聊天设置」里确认 `api_key` 已填写、`base_url` 和 `model` 与你使用的服务商一致
- 本项目默认模型是 `deepseek-v4-flash`，如果服务商不支持，可在「聊天设置」里改成它实际提供的模型名

**为什么有时候表情/动作不明显？**

- 情绪识别只对「强烈的情绪词」生效，普通回复会做轻点头的小反应
- 状态动作幅度可在 `tools/web/live.js` 的 `applyMotion()` 中调整数值

**菜单里选的表情会一直保持吗？**

- 手动选的表情在状态切换后会自动让位给状态绑定表情（思考→星星眼、执行→蚊香眼、完成→挥手、故障→黑脸、待机→爱心眼）
- 故障结束后表情会自动还原，不会一直黑脸

**如何添加/更换模型？**

- 把模型文件放到 `model/<名字>/` 目录，再写一个 `model/<名字>/model.json` 配置文件（参考 `model/yumi/model.json`），里面声明：
  - `model3`：模型入口文件（相对本目录）
  - `expressions`：表情 key → 文件路径（`heart`/`star`/`swirl`/`black`/`tear` 等为状态用 key）
  - `motions`：可手动播放的预设动作（group 名 + 显示名）
  - `presets`：各状态自动采用的动作/表情（`idle`/`thinking`/`working`/`completed`/`fault`/`interact`）
  - `effects`：加载后始终生效的表情（如隐藏水印）
  - `chat`：聊天情绪对应的表情
  - `crop`：显示裁切（不改原模型文件），如 `"crop": {"bottom": 0.14}` 表示把角色脚下底部 14% 的区域裁掉，可用于隐藏模型自带的版权文字/水印
- 重启桌宠后，右键 →「模型」即可选择新模型；模型在 `model3.json` 里声明的动作组（如 `Idle`）会自动作为预设动作
- 更省事的方式：右键 →「模型」→「导入模型（zip）」直接选择 Live2D 模型压缩包，或「导入模型（文件夹）」选择已解压的模型目录；程序会自动识别表情（星星眼/黑脸/脸红等）、姿势（扶脸/记笔记/看手机等）和动作，生成配置并切换到新模型

**状态动作怎么设置？**

- 右键 →「状态动作」→ 选择状态（如思考中）→ 选择想要的库内动作/姿势/表情
- 选「自动」或什么都不选，就用该模型的默认配置；选「无动作」则这个状态只摆基础站姿
- 设置按模型分别保存，切换模型互不影响；「恢复默认设置和模型」会清空所有设置
