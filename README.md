# Codex Live2D 桌宠

> **v4.0.0**：流式 TTS（DeepSeek 边出字边朗读）、本地记忆、聊天触发读屏幕、免按键语音对话、可自定义的 Soullink 动作。详见 [CHANGELOG.md](CHANGELOG.md)。

一个基于 Live2D 模型的透明桌面宠物：实时渲染、眼神跟随鼠标，并且能感知 Codex 的运行状态自动切换动作和表情；还内置了角色聊天模式，可以像朋友一样和角色对话。内置 **yumi** 模型，支持随时切换或导入其他 Live2D 模型。

![桌宠示意图](docs/preview.png)

## ✨ 功能

- **实时 Live2D 渲染**：QtWebEngine + pixi-live2d-display，无预渲染帧，角色一直在呼吸、摇摆
- **眼神/头部跟随鼠标**：光标在屏幕任意位置，角色都会看向它
- **Codex 状态联动**：读取 Codex 实时日志，自动切换状态
  - 待机 → 爱心眼 + 待机摇摆
  - 思考中 → 星星眼 + 托腮思考
  - 执行命令 → 蚊香眼 + 俯身忙碌
  - 完成 → 一次挥手
  - 故障 → 黑脸
  - 状态切换带柔和过渡动画，头顶气泡提示（思考中…/执行命令…/完成！/故障！）
- **模型切换**：右键 →「模型」子菜单可随时切换已安装的模型（yumi / 自行导入的模型）；当前模型会自动保存
- **动作预设 + 手动选择**：模型自带动作时自动采用，没有预设的状态回退到内置动作引擎
- **状态动作自定义**：右键 →「状态动作」可为每个状态（待机/思考中/执行中/完成/故障/点击互动）手动指定模型库里的动作、姿势或表情；未指定或指定的项不存在时，自动回退到默认动作配置
- **模型导入**：右键 →「模型」→「导入模型（zip）/（文件夹）」可直接导入新 Live2D 模型，自动识别表情、动作并生成配置
- **删除模型**：右键 →「模型」→「删除模型」可移除自己导入的模型（默认 yumi 不可删除）；删除当前正在用的模型会自动切回 yumi
- **聊天模式**：底部输入框和 yumi 对话
  - 回复以气泡漂浮在角色头顶
  - 根据回复情绪自动摆出动作和表情（开心→挥手爱心眼、难过→垂泪、生气→黑脸颤抖、思考→托腮、惊讶→后仰、中性→轻点头）
  - 回复采用流式生成：DeepSeek 边出字边逐句 TTS 朗读（Soullink 朗读队列逐句播放，未启用时独立 TTS 兜底），明显降低"等它说完才开口"的延迟
- **本地记忆**（默认开启）：右键 →「记忆」可管理
  - **短期记忆**：最近几小时内的对话保存在本地 `memory/short_term.jsonl`，重启桌宠后自动恢复，yumi 能接上之前的聊天
  - **长期记忆**：每轮对话后自动提炼重要事实（你的名字、喜好、约定、最近关心的事等），保存在本地 `memory/long_term.json`，去重合并、按重要度保留上限
  - **记忆召回**：每次回复前按当前话题召回最相关的长期记忆注入提示词（Embedding 语义检索，未配置 Key 时自动改用关键词匹配），yumi 会自然地想起你提到过的事
  - 主动发言和读屏看到的内容也会写入短期记忆，形成连贯的“经历”
  - 所有对话（聊天/主动发言/读屏）以短期记忆为主，长期记忆按当前话题相关度补充（不相关不注入）；两者都没有则按人设回答；人设始终是第一位约束，记忆只是背景，冲突时以人设为准
- **语音对话（免按键 + 唤醒词）**：右键 →「语音对话」→「开启」后，不用按任何键
  - 先对桌宠说唤醒词（默认「yumi」）唤醒，然后像打电话一样直接对话；基于 VAD 静音自动断句，说完一句停顿片刻（默认 0.8 秒）就自动识别
  - 回复自动用 TTS 朗读（默认百炼 Qwen-TTS / Cherry 音色），同时显示文字气泡
  - 开启语音对话会自动启动 Soullink 情绪引擎（表情驱动 + TTS 朗读）；关闭语音对话时，若 Soullink 是本功能自动开启的会一并关闭
  - 说「帮我看看」等话也会自动读屏幕再回答；记忆功能同步生效
  - 空闲超时或说「拜拜 / 退出对话 / 去忙吧」自动回到待唤醒状态
  - 唤醒词、静音断句时长、退出语、TTS 音色等都在「语音对话设置…」里配置
- **读屏幕**：右键 →「读屏幕」可开启定时观察屏幕
  - 按设定频率（默认 10 分钟）截屏，调用视觉大模型识别画面内容
  - 把识别结果交给聊天模型，让 yumi 以人设口吻回应一句
  - 聊天里说「帮我看看」「看看屏幕」「你能看到我的屏幕吗」等话，会自动读一次屏幕，并把画面内容和你的问题一起发给模型回答（需要已配置视觉接口）
  - 视觉模型接口（API 地址 / Key / 模型 / 提示词）在「读屏幕设置…」里配置
- **Soullink 情绪引擎**（可选开关）：右键 →「Soullink 情绪引擎」开启后
  - 情绪识别改用 [Soullink Emotion SDK](https://github.com/nanlingyin/soullink-emotion-sdk) 的 Embedding 分类（内置 1,400 条中文语料 + Top-K 投票，首次启用约 1 分钟初始化向量，之后自动缓存）
  - 动作和表情改由 Soullink 引擎驱动（连续 VAD 情绪 + FACS 表情 + 待机动作 + 说话口型）
  - 聊天回复自动用 TTS 朗读（默认百炼 Qwen-TTS / Cherry 音色）
  - 动作幅度可调：Soullink 设置里新增「动作幅度」（0.5x~2x），待机/思考/生气等摇晃与姿态统一放大，左右摇晃更明显；内置动作引擎同样生效
  - 手部动作姿势：好奇/疑惑时自动扶脸思考，累的时候看手机；长时间没互动时还会随机做扶脸、看手机、记笔记、前倾等小动作（模型自带对应表情才生效）
  - 每个模型可自定义待机动作：右键 →「Soullink 情绪引擎」→「选择待机动作姿势…」，勾选该模型自带的姿势（如扶脸/看手机/拿话筒/抬手等）作为待机随机小动作，设置按模型保存
  - 每个模型可自定义情绪动作：右键 →「Soullink 情绪引擎」→「选择情绪动作…」，为每个情绪指定对应姿势（如 累 → 看手机、好奇 → 扶脸），重新生成 profile 也不会丢失
  - 任意模型都能用：开启时若该模型还没有参数映射（`soullink.profile.json`），会自动扫描模型生成；导入新模型后也会自动补生成，也可在菜单里手动「生成/更新当前模型 profile…」
  - 开启期间自动禁用 Codex 状态动作匹配（思考中/执行中/完成/故障不抢动作），关闭后立即恢复
  - 关闭后恢复原来的关键词情绪识别和动作系统
- **右键菜单**：模型、动作、表情、放松、聊天模式、聊天设置、记忆、语音输入、语音对话、读屏幕、锁定拖动、放大缩小、恢复默认设置和模型、退出
- **裁切显示**：右键 →「裁切（从脚底往上）」可拖动滑块，按百分比从脚底往上裁掉显示区域（如裁 50% 只显示胸部以上），窗口会自动跟着变小；可随时重置为 0%
- **恢复默认**：一键把模型、大小、位置、锁定状态恢复为初始值（yumi）
- **透明置顶无边框窗口**，不挡工作区，窗口大小自适应角色，拖不丢

## 📦 环境要求

- Windows 10/11
- Python 3.10+（建议 3.12）
- 网络（首次安装依赖需要；聊天功能需要可用的 OpenAI 兼容接口）
- Soullink 情绪引擎需要 Node.js 18+（`node --version` 可查，本项目在 Node 24 下验证）

## 🚀 快速开始

### 1. 安装依赖（项目本地虚拟环境）

```powershell
cd codex-live2d
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install PySide6
.\.venv\Scripts\python.exe -m pip install "RealtimeSTT[faster-whisper]" silero-vad
```

### 2. 配置聊天接口（可选，不配置也能用 Codex 状态模式）

复制 `config.example.json` 为 `config.json`，填入你的接口信息：

```json
{
  "chat": {
    "base_url": "https://api.deepseek.com/v1",
    "api_key": "你的 API Key",
    "model": "deepseek-v4-flash",
    "persona": "角色人设……"
  }
}
```

`config.json` 已被 `.gitignore` 忽略，不会提交到仓库（防止 Key 泄露）。也可以在桌宠右键菜单 →「聊天设置…」里直接填写，效果相同。

读屏幕功能需要在 `config.json` 里额外配置视觉模型接口（同样可在右键菜单 →「读屏幕设置…」填写）：

```json
{
  "screen_read": {
    "enabled": false,
    "interval_minutes": 10,
    "vision": {
      "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
      "api_key": "你的视觉模型 API Key",
      "model": "qwen-vl-max",
      "prompt": "请仔细看这张屏幕截图，用中文简要描述屏幕上正在显示的内容……"
    }
  }
}
```

`enabled` 也可以通过右键菜单 →「读屏幕」→「开启读屏幕」随时开关。若本机已配置阿里云百炼的 `DASHSCOPE_API_KEY`，视觉 API Key 会自动复用，无需重复填写。

Soullink 情绪引擎依赖 SDK 的 npm 包，首次使用前需要安装一次（不装也能用原有关键词模式）：

```powershell
cd tools/soullink
npm install
```

安装完成后在桌宠右键菜单 →「Soullink 情绪引擎」→「开启」即可。Embedding 和 TTS 的 API Key 会自动复用本机百炼 Key（也可在「Soullink 设置…」里单独填写）。

记忆功能默认开启，数据全部保存在本地 `memory/` 目录（不入库）。可在右键菜单 →「记忆」里开关、查看或清空，也可以在「记忆设置…」里调整：

```json
{
  "memory": {
    "enabled": true,
    "short_term_max_messages": 40,
    "short_term_max_hours": 24,
    "long_term_extract": true,
    "long_term_max_entries": 200,
    "recall_top_k": 5,
    "use_embedding": true,
    "embedding": {
      "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
      "api_key": "",
      "model": "text-embedding-v3"
    }
  }
}
```

- 短期记忆：保留最近 `short_term_max_messages` 条、`short_term_max_hours` 小时内的对话
- 长期记忆：每轮对话后自动提炼事实并合并去重，超过 `long_term_max_entries` 条时自动淘汰重要度低的旧记忆
- 语义检索：开启 `use_embedding` 后，回复前用 Embedding 按话题召回最相关的记忆；未填写 Embedding Key 时自动退化为本地关键词匹配，不影响使用

### 3. 启动

双击 `启动桌宠.bat`，或运行：

```powershell
.\.venv\Scripts\pythonw.exe main.py
```

出问题时用 `调试运行.bat`（带控制台）查看报错。

## ⚙️ 配置文件

- `config.json`：聊天接口配置（`chat`）、记忆配置（`memory`）、读屏幕配置（`screen_read`）和 Soullink 配置（`soullink`），本地生成、不入库
- `settings.json`：窗口位置、大小、锁定状态、当前模型，运行时会自动保存
- 每个模型一个目录：`model/<id>/`，目录内的 `model.json` 声明模型文件名、动作预设、表情映射和状态绑定
- `memory/`：本地记忆数据（`short_term.jsonl` 短期对话流水 + `long_term.json` 长期事实库），由程序自动读写，已加入 `.gitignore`

## ❓ 常见问题

**启动后看不见小人？**

- 确认只启动了一个实例（重复启动可能互相遮挡）；右键多余的实例选择「退出」
- 桌宠不会掉出屏幕（已做边界限制），但可能被全屏应用盖住，可先最小化其他窗口
- 查看 `pet_error.log`（有报错时自动生成），把内容反馈给开发者

**聊天没反应 / 提示连接失败？**

- 在「聊天设置」里确认 `api_key` 已填写、`base_url` 和 `model` 与你使用的服务商一致
- 本项目默认模型是 `deepseek-v4-flash`，如果服务商不支持，可在「聊天设置」里改成它实际提供的模型名

**yumi 会记得之前聊过什么吗？**

- 默认开启本地记忆：短期记忆保存最近 24 小时（可调）内的对话，长期记忆每轮对话后自动提炼重要事实，重启桌宠后都还在
- 所有记忆只存在本机 `memory/` 目录，可在右键 →「记忆」→「查看记忆 / 清空记忆」里管理

**为什么有时候表情/动作不明显？**

- 情绪识别只对「强烈的情绪词」生效，普通回复会做轻点头的小反应
- 状态动作幅度可在 `tools/web/live.js` 的 `applyMotion()` 中调整数值

**菜单里选的表情会一直保持吗？**

- 手动选的表情在状态切换后会自动让位给状态绑定表情（思考→星星眼、执行→蚊香眼、完成→挥手、故障→黑脸、待机→爱心眼）
- 故障结束后表情会自动还原，不会一直黑脸

**如何添加/更换模型？**

- 把模型文件放到 `model/<名字>/` 目录，再写一个 `model/<名字>/model.json` 配置文件（参考 `model/yumi/model.json`），里面声明：
  - `model3`：模型入口文件（相对本目录）
  - `expressions`：表情 key → 文件路径（`heart`/`star`/`swirl`/`black`/`tear` 等为状态用 key）
  - `motions`：可手动播放的预设动作（group 名 + 显示名）
  - `presets`：各状态自动采用的动作/表情（`idle`/`thinking`/`working`/`completed`/`fault`/`interact`）
  - `effects`：加载后始终生效的表情（如隐藏水印）
  - `chat`：聊天情绪对应的表情
  - `crop`：显示裁切（不改原模型文件），如 `"crop": {"bottom": 0.14}` 表示把角色脚下底部 14% 的区域裁掉，可用于隐藏模型自带的版权文字/水印
- 重启桌宠后，右键 →「模型」即可选择新模型；模型在 `model3.json` 里声明的动作组（如 `Idle`）会自动作为预设动作
- 更省事的方式：右键 →「模型」→「导入模型（zip）」直接选择 Live2D 模型压缩包，或「导入模型（文件夹）」选择已解压的模型目录；程序会自动识别表情（星星眼/黑脸/脸红等）、姿势（扶脸/记笔记/看手机等）和动作，生成配置并切换到新模型

**状态动作怎么设置？**

- 右键 →「状态动作」→ 选择状态（如思考中）→ 选择想要的库内动作/姿势/表情
- 选「自动」或什么都不选，就用该模型的默认配置；选「无动作」则这个状态只摆基础站姿
- 设置按模型分别保存，切换模型互不影响；「恢复默认设置和模型」会清空所有设置
